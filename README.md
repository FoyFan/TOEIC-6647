## macOS 应用安装

1. 下载 `TOEIC.app.zip` 并解压
2. 将 `TOEIC.app` 拖入「应用程序」文件夹
3. 首次打开：**右键点击 → 打开**（应用为本地签名，绕过 Gatekeeper 提示）
4. 需要系统允许「语音」权限以使用朗读功能

### 应用功能

- **卡片 / 列表** 两种浏览模式（列表总览 + 单卡精读）
- 键盘操作：`↑↓` 切换单词 · `←→` 快进 10 个 · `Space` 发音 · `F` 收藏 · `G` 切换列表总览
- 分类浏览 · 搜索 · 收藏夹 · 学习进度（侧边栏进度环）
- 常用短句 16 组 · 备考指南
- 收藏与学习进度保存在本地（浏览器 localStorage），不上传任何数据
